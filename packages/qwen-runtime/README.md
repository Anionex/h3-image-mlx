# H3 Image MLX — Qwen native runtime

Standalone native MLX worker for Qwen Image 2.1 generation and editing on Apple Silicon, macOS 26.2 or later. Includes dynamic libraries, Metal resources and third-party licenses; no model weights or desktop app is required.

Install with the public Python API:

```bash
python -m pip install 'h3-image-mlx[qwen]==0.1.0a5'
```

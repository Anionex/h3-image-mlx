- H3 can load page-aligned DiT and text encoder weights through read-only file mappings with `H3_ZERO_COPY=1`. Prepare the checkpoints with `h3-image-mlx align`. Pass `--keep-original` to retain the source files.
- `H3_GPU_BUDGET_MB` sets the memory budget used to size the optional DiT buffer cache.
- `align` verifies each replacement against the pinned checkpoint before removing the source. `verify` checks the original metadata and tensor bytes of aligned checkpoints, including when the source file has been removed. For copies made before this release, restore any missing originals with `fetch` and run `align` again to enable SHA-256 verification.

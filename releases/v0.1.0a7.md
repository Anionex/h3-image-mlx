# Faster H3 portable INT8 generation

On macOS 26.4 and later, the portable backend checks whether the GPU can multiply two INT8 matrices directly into an INT32 output. Longer aligned projections use this path when the probe succeeds. A full-row MLX fallback reuses activations across output channels. The small-projection SIMD path remains available.

On a 48 GB M5 Pro running the portable backend, median 1024×1024 generation time fell from 141.84 s on v0.1.0a6 to 41.13 s (71.0% less elapsed time). The original portable baseline took 156.25 s (73.7% less elapsed time). The highest stage process footprint with direct TensorOps was 2.65 GB. All thirteen six-step PNGs were byte-identical with verified uncached weight reads. Physical M1–M4 generation times remain unmeasured.

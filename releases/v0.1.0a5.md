# 0.1.0a5

Qwen Image 2.1 Turbo joins H3 through a shared CLI and Python API. The optional native runtime is packaged separately; H3 installations retain their existing inference path.

```bash
python -m pip install 'h3-image-mlx[qwen]==0.1.0a5'
```

Qwen supports text-to-image, ordered reference editing, variation, RGBA, independently scaled LoRA stacks, sampling presets, CFG, memory modes, progress and cancellation. Prompt enhancement is excluded. Qwen's native runtime requires Apple Silicon and macOS 26.2 or later.

Verified uncached eight-step generation on M5 Pro 48 GB (three trials per size):

| Resolution | Median time | Highest worker footprint |
| --- | ---: | ---: |
| 512×512 | 16.94 s | 0.846 GB |
| 1024×1024 | 47.67 s | 1.408 GB |

Weight-file residency stayed at zero throughout these measurements. All three stages are included; prepared weights already existed. Worker footprint is separate from total system memory. Full measurements and original JSON are in BENCHMARKS.md.

Validation includes 31 installed-wheel tests, real Qwen generation/editing/LoRA/cancellation, and an H3 image matching 0.1.0a4 pixel for pixel. The portable backend ran on M5; M1–M4 hardware coverage remains outstanding.

Release assets include the main wheel/source distribution and `h3-image-mlx-qwen-runtime==0.1.0a1` native wheel. The native wheel uses the standard macOS major-version platform tag and checks its exact minimum OS before starting. No model weights are redistributed.

# H3 portable INT8 acceleration

Streamed H3 INT8 inference now prefetches one denoiser block and evaluates the current block asynchronously. A Metal SIMD-group kernel reads INT8 inputs directly for smaller projection shapes. Larger shapes use standard MLX. Set `H3_PREFETCH=0 H3_ASYNC=0` to select synchronous block reads.

On a 48 GB M5 Pro explicitly running the portable backend, 512×512 six-step end-to-end latency fell from a median of 124.28 s to 56.40 s (54.6% lower, three runs per version). A 1024×1024 pair measured 257.35 s and 219.36 s (14.8% lower). Both versions bypassed the model-weight filesystem cache. Outputs matched byte for byte at each resolution. Physical M4 timing is still pending.

[Benchmark conditions and trial data](https://github.com/Anionex/h3-image-mlx/blob/v0.1.0a6/BENCHMARKS.md#h3-portable-int8-generation).
